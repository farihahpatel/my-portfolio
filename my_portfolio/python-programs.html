1. Grade GeneratorTakes marks as input and prints a grade using if-elif-else. Rejects marks outside 0-100. 
print("Grade Generator")
# Get the input
marks = float(input("Enter your marks: "))
# Decision-making using if-elif-else statement
if marks > 100 or marks < 0:
    print("Invalid marks!")
else:
    if marks >= 90:
        print("Grade: A")
    elif marks >= 80:
        print("Grade: B")
    elif marks >= 70:
        print("Grade: C")
    elif marks >= 60:
        print("Grade: D")
    else:
        print("Grade: F")
2. Even Number CheckReads 5 numbers into a list and uses any() to check whether at least one is even. 
number = []
for i in range(5):
    a = int(input("Enter a number:"))
    number.append(a)
ans1 = any(num % 2 == 0 for num in number)
if ans1:
    print("Some are even")
else:
    print("None are even")
3. Pass Check for 5 SubjectsReads marks of 5 subjects and uses all() to check whether every mark is at least 40. 
m = []
for i in range(5):
    a = int(input("Enter marks:"))
    m.append(a)
print(m)
ml = all(y >= 40 for y in m)
if ml:
    print("All pass")
else:
    print("Some failed")
4. Symptom CheckerAsks about fever, cough and headache and prints a basic result using if-elif-else and logical operators. 
fever = input("Fever?").lower()
cough = input("Cough?").lower()
headache = input("Headache?").lower()

if fever == "yes" and cough == "yes":
    print("Possibly flu")
elif fever == "yes" and headache == "yes":
    print("Possibly viral flu")
elif cough == "yes":
    print("Possibly cold")
else:
    print("no illness detected")
5. Loan EligibilityApproves a loan only if age, salary and credit score all meet the minimum conditions. 
age = int(input("Enter the age:"))

credit = int(input("Enter your credit score:"))
if age >= 21 and salary >= 30000 and credit >= 700:

6. Admission, Scholarship and Hostel EligibilityUses chained conditions: marks decide eligibility, then entrance exam, income and hostel need decide the rest. 
marks = int(input("Enter your marks:"))
entrance = input("have you passed the entrance exam?:").lower()
income = int(input("Enter the annual income:"))
hostel = input("do you require hostel?:").lower()

eligible = False
admission = False
scholarship = False
hs_allotted = False

if marks >= 80:
    eligible = True
if eligible and entrance == "yes":
    admission = True
if admission and income < 300000:
    scholarship = True
if scholarship and hostel == "yes":
    hs_allotted = True

print("Eligible:", eligible)
print("Admission:", admission)
print("Scholarship:", scholarship)
print("Hostel allotted:", hs_allotted)
